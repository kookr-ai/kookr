The idea: the box never grows

One real four-line notebook file sits in the same rectangle for the whole film. Everything the product does happens to its lines: a lesson is added, voted up, voted down, pushed out. The rectangle never moves and never gets bigger, because that is the product's point.

Every command, id, score and output line on screen is real output of nb 0.10.0, captured from a temporary notebook with the cap set to 4 lines so an eviction fits on screen. The only staged text is the failing test in the hook and the passing test in the payoff.

Storyboard

Three directions considered

Chosen

The box never grows

Open on the pain (same trap, three days), then stage the whole mechanism on one fixed file. Strongest for a first-time viewer and the only one with a built-in big moment: the eviction.

Folded in

Agent memory you can cat

Cold open on the file in a terminal, proof first. The skeptics' favourite, but a quiet opening for a feed. It survives as the paper scene with the real diff.

Folded in

What should memory forget?

Lead with forgetting as the feature. The most original angle, but it only lands on people who already think about memory design. It survives as the cap scene.
