# Kookr

**A smart attention router for developers running multiple AI coding agents.**

</div>

You run several Claude Code or Codex CLI agents in parallel. One silently loops on the same failing test for the 50th time. Another asks a permission question. A third drifts off-task. Which one needs you?

**Kookr watches them all, detects failure patterns, and routes your attention to the agent that needs you most.**

## Projects

- **[kookr-ai/kookr](https://github.com/kookr-ai/kookr)** — the supervisor dashboard, agent adapters, and Kookr Toolkit Claude Code plugin. Apache-2.0.

## Contributing

Contributions are welcome. Start with the [main README](https://github.com/kookr-ai/kookr#readme) and the [CLA](https://github.com/kookr-ai/kookr/blob/main/CLA.md) — the CLA-Assistant bot will prompt you on your first PR.

CLA signatures are tracked privately in `kookr-ai/cla-signatures`. The repo is kept private to avoid surfacing contributor email addresses captured by the CLA-Assistant action; the CLA text itself is public in the main repo.
