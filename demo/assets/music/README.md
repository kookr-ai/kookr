# Demo Music Bed

Drop ONE license-free music track here (mp3/wav/m4a/ogg/flac). The demo
recorder picks the first audio file alphabetically, loops it to the video
length, mixes it at ~9% volume under the narration, and fades it in over 2s
and out over the final 3s.

No file here → the demo ships narration-only (the recorder logs a one-liner).

Requirements for any track you add:
- License must permit redistribution in a published video (CC0 / CC-BY with
  attribution in the YouTube description, or a purchased license).
- Calm, low-dynamic instrumental — it sits UNDER speech. No vocals.
- Note the source + license in this file when you add one.

Current track: none.
